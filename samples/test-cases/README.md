# Тестовые наборы данных

Набор CSV-файлов для ручной проверки двух подсистем оценки поставщиков.

Колонки CSV: **дата \t наём \t полнота \t дефекты**. Пустое значение помечается `-`.
Чтобы сделать значение «экспертной оценкой» (`(?)`), даётся дублированная строка для той же даты с другим значением (или с пустым в одном из дублей).

## Что проверяет каждый кейс

| # | Файл | Что проверяет | Ожидаемое поведение |
|---|---|---|---|
| 01 | good-all-precise | Идеальный поставщик, все точные данные | Обе системы → green |
| 02 | bad-all-precise | Плохой поставщик, все точные | Обе → red |
| 03 | mid-yellow | Средний поставщик | Обе → yellow |
| 04 | trend-improving | Сильный восходящий тренд | Обе → green |
| 05 | trend-degrading | Сильный нисходящий тренд | Обе → red |
| 06 | expert-history | Экспертные оценки в истории, последняя точная | Fuzzy работает на хвосте; Multiop включает статусы 5/6 в таблицу |
| 07 | expert-last-only | Только последняя точка — экспертная | Fuzzy блокируется (не работает с неточностями в last); Multiop работает |
| 08 | missing-defects-start | Пропуски в начале по дефектам | Fuzzy обрезает; Multiop помечает defects как «направление неопределено» |
| 09 | missing-c-middle | Пропуски в середине по полноте | Fuzzy обрезает; Multiop status 4 для c |
| 10 | missing-lh-last | Последний наём отсутствует | Fuzzy блокируется; Multiop status 4 для lh |
| 11 | mixed-quality | Эксперт в одной метрике, пропуски в другой | Multiop: status 5/6 для lh, status 4 для d |
| 12 | boundary-values | Все значения ровно на пиках термов | Fuzzy: 1 правило (μ=1 только для M); Multiop: 9 правил (более широкие диапазоны) |
| 13 | volatile | Сильно колеблющиеся, но все точные | Обе системы сходятся |
| 14 | fully-uncertain | Пропуски во всех метриках | Fuzzy блокируется; Multiop — баннер «неопределённости» по всем метрикам |
| 15 | only-experts | Все исторические значения наёма — экспертные | Fuzzy блокируется (нет точного хвоста); Multiop работает |

## Как использовать

1. В дашборде нажми «Импорт CSV», выбери файл из этой папки.
2. Сравни итоговые оценки fuzzy и multiop.
3. Проверь, что плашка над таблицей multiop корректно описывает источники неточностей/неопределённостей.
4. Для fuzzy проверь, что баннер «Использовано N из M» отображается только при обрезке и `status === ok`.

## Условные обозначения качества (в таблице сводки)

- ✓ — все значения точные (`quality=1`)
- ? — есть экспертные оценки (`quality=2`), без пропусков
- ø — есть пропуски (`quality=0`)
