# Тестовые наборы данных

Набор CSV-файлов для ручной проверки двух подсистем оценки поставщиков.

Колонки CSV: **дата \t наём \t полнота \t дефекты**. Пустое значение помечается `-`.
Чтобы сделать значение «экспертной оценкой» (`(?)`), даётся дублированная строка для той же даты с другим значением (или с пустым в одном из дублей).

## Как использовать

1. В дашборде нажми «Импорт CSV», выбери файл из этой папки.
2. Сравни итоговые оценки fuzzy и multiop.
3. Проверь, что плашка над таблицей multiop корректно описывает источники неточностей/неопределённостей.
4. Для fuzzy проверь, что баннер «Использовано N из M» отображается только при обрезке и `status === ok`.

## Условные обозначения качества (в таблице сводки)

- ✓ — все значения точные (`quality=1`)
- ? — есть экспертные оценки (`quality=2`), без пропусков
- ø — есть пропуски (`quality=0`)

## Наблюдения по сравнительному анализу

- **Точные данные (01–05, 13)** — обе системы дают идентичный набор правил и идентичный балл. Унификация через `computeRuleCrisp` выполняется.
- **Эксперт в истории (06)** — обе совпадают.
- **Эксперт только в последней точке (07, 19)** — fuzzy блокируется, multiop работает (это типовая выгода multiop).
- **Пропуски в середине или начале (08–11, 18)** — fuzzy обрезает до точного хвоста, multiop активирует «оба направления» для метрик с пропусками и помечает их статусом 4.
- **Пропуски в последней точке (10, 14, 15, 16, 19, 20, 21, 23, 25)** — fuzzy чаще блокируется, multiop почти всегда даёт результат.
- **Boundary (12, 22)** — fuzzy выдаёт меньше правил из-за того, что трапеция в граничной точке имеет μ=0 в соседних термах, а multiop включает все термы с диапазоном, содержащим граничное значение. Балл оба дают близкий.
- **Эксперт vs точное на границе (12 vs 22)** — тот же набор правил, тот же балл, но в multiop разный бейдж (status 2 → status 6) и плашка «...с неточностями».
- **Полная неопределённость (14, 17, 23, 25)** — fuzzy блокируется (или работает на маленьком хвосте), multiop активирует все 216 правил со статусом 4. Балл показывает «среднее по всем правилам базы знаний» — yellow.
