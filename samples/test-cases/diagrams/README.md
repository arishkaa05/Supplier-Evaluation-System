# Блок-схемы алгоритмов (по ГОСТ 19.701-90)

Drawio-файлы с блок-схемами математических ядер обеих ИС. Каждый файл —
самостоятельная схема:

- [`fuzzy.drawio`](./fuzzy.drawio) — нечёткая логика
- [`multiop.drawio`](./multiop.drawio) — теория мультиопераций
- [`crisp.drawio`](./crisp.drawio) — общий расчёт crisp-балла одного правила

## Условные обозначения (ГОСТ 19.701-90)

| Символ | Назначение |
|---|---|
| Овал | Начало / Конец процесса |
| Параллелограмм | Ввод / Вывод данных |
| Прямоугольник | Процесс (вычислительное действие) |
| Прямоугольник с двойными вертикальными границами | Предопределённый процесс (ссылка на отдельную схему) |
| Ромб | Решение (условный переход) |
| Стрелка | Поток управления |

Линии — только ортогональные (горизонтальные / вертикальные с поворотами
90°). Стрелки направлены сверху вниз / слева направо по основному потоку.

## Как открыть

1. Бесплатное веб-приложение: <https://app.diagrams.net>
   → File → Open from → Device → выбрать `.drawio`.
2. Desktop-версия: <https://github.com/jgraph/drawio-desktop/releases>.
3. Расширение для VS Code: «Draw.io Integration» (hediet.vscode-drawio).

## Экспорт в другие форматы

В drawio: File → Export as → PNG / SVG / PDF.

Для пакетного экспорта:

```bash
# через drawio-desktop CLI
drawio --export --format svg --output diagrams.svg fuzzy.drawio
```
